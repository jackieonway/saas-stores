# 门店成员校验

门店负责人、员工关联和日报业务分别持有自己的领域数据。平台只提供当前身份、组织范围和受控成员查询，门店不访问平台用户表。

## 查找和写入

memberLookups 需要在平台 DATA_GRANT_POLICY 中按资源/动作显式登记，且当前调用者具备相同操作的 permission 和数据授权。普通业务 Bearer 查指定组织的有效直接成员，不需要平台用户管理权限。

业务更新先按当前范围非锁定读取，再释放连接调用平台；短事务取得锁后复核目标、旧值、version、组织及期限。目录返回的历史结果不是永久成员资格，不能在锁后续期，也不能用负责人变动扩大 owner 范围。

## 失败与恢复

成员请求开始计时，窗口为 min(PLATFORM_AUTH_TIMEOUT_MS,3000ms)。授权或成员校验在提交前过期则拒绝并回滚；提交后不能确认结果时先读取业务事实。短窗口仍不能消除两个数据库间的撤销竞态。

前端切换身份/组织或授权替换后清除旧视图并取消旧请求；同身份合法续期也要重读编辑版本。路由、金额、日期与写入错误见 [API](../API.md)。
